Arquitectura Defensiva & Ciberseguridad

Blindaje Perimetral, Bóveda AES-256 y Aislamiento Multi-Tenant

Protección de grado bancario e industrial. Cero exposición directa a internet, cifrado de reposo y en tránsito, y aislamiento estricto de bases de datos para garantizar la integridad absoluta de sus operaciones.

1. Aislamiento Físico y Lógico: Schema-per-Tenant

PostgreSQL 16

A diferencia de los sistemas SaaS convencionales que comparten tablas con una simple columna tenant_id (vulnerables a inyección o bugs de consulta), en CalcuSuiteIA cada cliente dispone de un esquema relacional propio dentro de PostgreSQL 16. La sesión de base de datos se bloquea con SET search_path = tenant_xyz, imposibilitando físicamente cualquier acceso cruzado de información.

2. Bóveda Criptográfica AES-256 (Vault Interno)

PBKDF2 HMAC-SHA256

Las credenciales de acceso a APIs (Mercado Libre, pasarelas de pago, tokens bancarios y certificados digitales de facturación electrónica CFE) se almacenan cifradas en reposo mediante el algoritmo AES-256 en modo GCM con vector de inicialización único y derivación de claves PBKDF2. Los secretos jamás se persisten en texto plano ni se imprimen en logs de aplicación.

3. Cloudflare Zero Trust & Mitigación CWE-350

Zero Exposure

Los servidores de CalcuSuiteIA no tienen puertos expuestos directamente a internet (cero riesgo de escaneo de puertos o ataques de denegación de servicio no mitigados). El tráfico externo hacia app.calcusuiteia.com fluye a través de un túnel cifrado Cloudflare Zero Trust en HTTPS 443 estándar, con listas blancas de hosts estrictas para prevenir ataques de DNS Rebinding (CWE-350).

4. 2FA TOTP (RFC 6238) & RBAC de 8 Roles

Granular Security

Autenticación de doble factor obligatoria para perfiles administrativos y contables mediante contraseñas temporales TOTP (Google Authenticator / Authy). Modelo de permisos por roles estricto (RBAC) con 8 niveles segregados: Operario de Almacén, Chofer de Flota, Cajero de Cobranzas, Encargado WMS, Contador General, Auditor de Cumplimiento, Gerente de Operaciones y SuperAdministrador.

5. Pistas de Auditoría Inmutables (Append-Only)

ISO 27001 Ready

Cada movimiento de stock, cambio de coordenadas espaciales de estanterías, emisión de comprobantes o transferencia de fondos genera un registro de auditoría transaccional inmutable. Se captura el hash del usuario, dirección IP, marca temporal en microsegundos y estado anterior/posterior del registro contable o físico.
